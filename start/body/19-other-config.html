Configuring nginx and other servers

As noted in the caveats above, nginx and some other popular modern web servers no longer support CGI at all... out of the box. For servers like these, you'll need to use a wrapper. Instructions here are minimal, as we have not tested this, but this sample nginx.conf using fcgiwrap should work, placed inside of your server { } block in place of the existing location / entry: 

location ~ (^|/)(sys|body)(/|$) { return 403; }
location ~ (^|/)\.              { return 403; }
location / { index index.html index.cgi; }
location ~ \.cgi$ {
    include fastcgi_params;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    fastcgi_pass unix:/run/fcgiwrap.socket;
}

Keep in mind that the path /run/fcgiwrap.socket can vary by distribution.
