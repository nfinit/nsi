Get NSI

NSI's official repository is hosted on GitHub, and can be downloaded as an archive from there, or by a simple command-line clone from your web server's document directory: 

$ git clone https://github.com/nfinit/nsi .

This command will download the NSI engine and demo site into your current directory. If you successfully configure your server in the next step, or you've already prepared, you will be hosting a copy of this site ready to customize!
