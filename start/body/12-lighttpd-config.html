Configuring Lighttpd

If Apache is too heavy for you or you don't need all of its features, Lighttpd is an excellent modern alternative, and generally our server of choice.

Like Apache, running NSI on Lighttpd requires optional modules that are still typically bundled in most packages: mod_access and mod_cgi. mod_cgi is often not enabled by default, so you'll likely need to uncomment or add it to your lighttpd.conf file.

Unlike Apache, Lighttpd doesn't support local configuration files like .htaccess, so you'll need to configure the server in lighttpd.conf: 

server.modules += ( "mod_access", "mod_cgi" )
cgi.assign = ( ".cgi" => "" )
index-file.names += ( "index.cgi" )
$HTTP["url"] =~ "(^|/)(sys|body)(/|$)|(^|/)\." {
    url.access-deny = ( "" )
}

If your lighttpd.conf already has a cgi.assign line present, add ".cgi" ==> "" to it instead of adding a second line.

Once these changes are applied, restart Lighttpd to re-load the configuration.
