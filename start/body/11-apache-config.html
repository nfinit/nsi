Configuring Apache

Apache HTTP Server has long been among the world's most popular web servers, with a rich feature set, good multiplatform support and ready availability. It's often pre-installed on modern Linux and Unix systems, and NSI has been developed and tested on both Apache 1.x and 2.x. Apache can be heavy compared to other servers, but its flexibility and powerful configuration makes us recommend it, especially if you aren't sure what to pick.

Running NSI on Apache requires both mod_cgi and mod_rewrite to be installed and available. These are often included in Apache packages, but rarely enabled. You will likely need to enable them in your Apache configuration file (httpd.conf or apache2.conf) or, on Ubuntu and other Debian family Linux distributions, with the a2enmod command: 

a2enmod cgi rewrite

Once you've verified you have the required modules installed and enabled, you'll need to verify Apache's configuration supports CGI execution. If you're setting up NSI on a shared host or other server with AllowOverride All configured, you can simply add these lines to the top of NSI's bundled .htaccess file: 

Options +ExecCGI
AddHandler cgi-script .cgi
DirectoryIndex index.html index.cgi

Alternately, you'll need to edit your Apache server configuration file, for example if your website is in the directory /var/www/html, you can configure it for NSI with this: 

<Directory "/var/www/html">
    Options +ExecCGI
    AllowOverride FileInfo
    AddHandler cgi-script .cgi
    DirectoryIndex index.html index.cgi
</Directory>

Once you've applied your changes, you'll need to restart Apache to reload its configuration.
